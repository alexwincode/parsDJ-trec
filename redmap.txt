Модуль 1: Локальный «движок» загрузки и анализа (Основа софта на ПК)
Это ядро бэкенда, которое будет работать на вашем ноутбуке.
Задача 1.1: Коннектор к Яндекс Музыке. Написать скрипт, который по ID трека или ссылке вытягивает чистые метаданные: артиста, название, обложку (cover_url), аудио-превью (preview_url), жанр и встроенный флаг explicit.
Задача 1.2: Парсер PromoDJ (Клубный источник). Написать базовый скрапер на BeautifulSoup/requests, который принимает запрос со словом "remix/mashup", ищет трек на PromoDJ, фильтрует по рейтингу PR и вытягивает прямую ссылку на скачивание и превью.
Задача 1.3: Интеграция Gemini API (Цензура). Реализовать функцию отправки текста песни (или метаданных) в Gemini для глубокого контекстного анализа (категории риска: Green/Yellow/Red для банкетов).
Задача 1.4: Локальный аудио-процессор (BPM & Громкость). Написать функцию, которая с помощью librosa определяет BPM файла, а с помощью pydub/FFmpeg нормализует громкость скачанных треков до единого стандарта (например, -14 LUFS).
Модуль 2: Облачная база данных (Синхронизация)
Организация бесплатного и легкого обмена данными между вами и коллегой.
Задача 2.1: Проектирование JSON-архитектуры. Утвердить финальный формат карточки трека (ID, артист, название, жанр, BPM, статус цензуры, дата добавления, ссылки на превью/обложку).
Задача 2.2: Скрипт синхронизации с Google Диском. Написать модуль на Python (google-api-python-client), который умеет незаметно скачивать и перезаписывать файлы метаданных в вашей общей папке на Диске.
Задача 2.3: Реализация раздельных JSON. Переписать логику так, чтобы каждый трек сохранялся как отдельный файл id_трека.json (защита от конфликтов, если вы с коллегой добавляете треки одновременно).
Модуль 3: Веб-интерфейс для коллеги (GitHub Pages)
Создание бесплатного сайта, который не требует вашего включенного ПК.
Задача 3.1: Верстка адаптивной витрины. Создать простую HTML/CSS (или Tailwind) страницу, оптимизированную под мобильные телефоны, с сортировкой треков по дате добавления (date_added).
Задача 3.2: JS-интеграция с Google Drive API. Написать JavaScript-код для фронтенда, который принимает ключ авторизации (токен) коллеги, читает папку с JSON-файлами на Диске и рендерит красивые карточки с обложками и кнопкой плеера для 30-секундного превью.
Задача 3.3: Кнопка «Добавить трек» на фронте. Реализовать форму, куда коллега вставляет ссылку, а JS формирует новую JSON-карточку и отправляет её в облако.
Модуль 4: Локальный пульт управления (FastAPI)
Сборка всего воедино на вашем диджейском ноутбуке.
Задача 4.1: Маршруты FastAPI. Объединить все локальные скрипты в API-эндпоинты (/search, /download, /sync).
Задача 4.2: Фоновый мониторинг облака. Настроить фоновую задачу (Background Task) в FastAPI, которая раз в минуту проверяет появление новых файлов на Google Диске от коллеги.
Задача 4.3: Локальный дашборд диджея. Сделать для себя простую веб-панель, где выводятся уведомления: «Коллега добавил трек [Обложка]», кнопка прослушивания превью и кнопка «Скачать оригинал в 320kbps + зашить BPM в ID3-теги».
Модуль 5: Полевая адаптация (Для заказов и банкетов)
Дополнительные фичи для работы на площадке.
Задача 5.1: Локальный QR-заказ. Вывести на ваш FastAPI-интерфейс генерацию QR-кода, сканируя который, ведущий на банкете попадает на локальный IP вашего ноута и может закидывать «экстренные заказы» прямо вам в пульт в обход ограничений интернета.
Задача 5.2: Генератор .m3u плейлистов. Написать функцию, которая автоматически собирает все одобренные вами треки за текущий день в стандартный файл плейлиста для мгновенного импорта в Rekordbox или Serato.
